# 🌿 Olivunas

**Aplicación web para la gestión de explotaciones agrícolas.**

Olivunas es un proyecto personal que nace de una necesidad real: facilitar la gestión diaria de una explotación agrícola familiar mediante una herramienta digital clara y accesible.

El objetivo es centralizar la información de **fincas, trabajadores y jornadas laborales** y reducir la dependencia de registros manuales.

> 🚧 **Estado:** proyecto en desarrollo. La interfaz está en construcción; el backend, la base de datos y el almacenamiento persistente todavía no están implementados.

## 🎯 Objetivos

- Organizar las fincas de una explotación, tanto propias como ajenas.
- Gestionar la información de los trabajadores y sus tarifas por hora o jornal.
- Registrar jornadas por fecha, finca y trabajador.
- Facilitar el seguimiento de las horas trabajadas y los costes de personal.
- Ofrecer una experiencia de uso sencilla, adaptable a distintos dispositivos.

## 🚀 Ejecutar el proyecto en local

**Requisitos:** Node.js y npm instalados.

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Luis1468/olivunas.git
   ```

2. Accede a su carpeta:

   ```bash
   cd olivunas
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

Abre en el navegador la dirección local que aparezca en la terminal.
